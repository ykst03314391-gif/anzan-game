# 算数暗算ゲーム

小学生向けの算数暗算練習Webアプリ。  
暗算が苦手な子どもが楽しみながら練習できることを目指す。

---

## 対象ユーザー

- 小学1年生〜6年生
- 暗算が苦手な子ども

---

## 機能要件

### 1. 学年選択

- 小学1年生〜6年生の6段階から選択
- 学年に応じて出題範囲が変わる

| 学年 | たし算・ひき算 | かけ算 | わり算 |
|------|----------------|--------|--------|
| 1年 | 1桁+1桁（〜10） | — | — |
| 2年 | 2桁+2桁 | 九九（1〜9） | — |
| 3年 | 3桁+3桁 | 2桁×1桁 | 九九の逆（÷1〜9） |
| 4年 | 4桁+4桁 | 3桁×2桁 | 2桁÷1桁 |
| 5年 | 小数・分数（将来対応） | 小数×整数（将来対応） | 小数÷整数（将来対応） |
| 6年 | 小数・分数（将来対応） | 分数×整数（将来対応） | 分数÷整数（将来対応） |

### 2. 計算の種類

以下の5種類から選択：

- たし算（＋）
- ひき算（−）
- かけ算（×）
- わり算（÷）
- ランダム（4種混合）

### 3. ゲームモード

#### モード1：問題数チャレンジ
- 問題数：10問 / 20問 / 30問 から選択
- 指定した問題数を解き終わるまでの**合計時間**を計測
- 短い時間ほど高ランク

#### モード2：制限時間チャレンジ
- 制限時間：1分 / 3分 / 5分 から選択
- 制限時間内に解けた**問題数の合計**を計測
- 多い問題数ほど高ランク

### 4. ユーザー登録

- 設定画面でユーザー情報を登録・編集できる
- 複数ユーザーの登録に対応（家族・兄弟での共用を想定）
- 登録できる情報：
  - **名前**（ランキングや結果画面に表示）
  - **キャラクター**（アンロック済みのキャラクターの中から選択）
  - **学年**（デフォルトの学年として使用）
- ゲーム開始時にユーザーを選択してプレイ

### 5. 答えの入力方法

- キーボード入力・タッチボタン（画面上の数字ボタン）の両対応
- **設定画面**で切り替え可能

### 6. キャラクター・演出（ゲーム中）

- ユーザーが選択したキャラクターをゲーム中に表示
- **正解**：にっこりした表情に変化
- **不正解**：残念な表情に変化

#### 使用キャラクター（全5種）

| キャラクター | フォルダ名 |
|------------|-----------|
| カービィ | kirby |
| メタナイト | metaknight |
| ワドルディ | waddledee |
| デデデ大王 | dedede |
| エフィリン | elfilin |

各キャラクターに3種類の画像を用意する：

| ファイル名 | 使用場面 |
|-----------|---------|
| normal.png | 通常時（問題表示中） |
| happy.png | 正解時 |
| sad.png | 不正解時 |

### 7. ご褒美システム

#### ① キャラクターアンロック

- 最初はカービィのみ使用可能
- ユーザーごとの累計正解数に応じて順番に解放される
- アンロック時にお祝い演出を表示

| 解放条件（累計正解数） | 解放キャラクター |
|----------------------|----------------|
| 最初から | カービィ |
| 50問 | メタナイト |
| 150問 | ワドルディ |
| 300問 | デデデ大王 |
| 500問 | エフィリン |

#### ③ バッジ・称号（実績）

- 条件を達成するとバッジを獲得
- コレクション画面で一覧表示

| バッジ名 | 獲得条件 |
|---------|---------|
| はじめの一歩 | はじめて1問正解 |
| 10問クリア | 累計正解数10問 |
| 100問クリア | 累計正解数100問 |
| 1000問クリア | 累計正解数1000問 |
| スピードスター | モード1で全問1分以内に完了 |
| パーフェクト | 1ゲームで全問正解 |
| 全キャラ制覇 | 全キャラクターをアンロック |
| コレクター | 全イラストをアンロック |
| ランキング入り | はじめてランキングに入る |

#### ④ 特別イラストのアンロック

- 累計正解数に応じて特別イラストが解放される
- ギャラリー画面で獲得済みイラストを一覧表示

| 解放条件（累計正解数） | 内容（例） |
|----------------------|-----------|
| 30問 | カービィ お祝いイラスト |
| 100問 | メタナイト かっこいいイラスト |
| 200問 | ワドルディ かわいいイラスト |
| 400問 | デデデ大王 豪快イラスト |
| 600問 | エフィリン ふわふわイラスト |
| 1000問 | 全員集合イラスト |

### 8. ランキング

- 各ランキングはトップ10を記録・表示
- ゲーム終了時にランキング入りした場合、名前を入力できる
- ランキングの評価基準：
  - モード1：合計時間（短い順）
  - モード2：正解問題数（多い順）
- ランキングは以下の組み合わせで個別管理：
  - 学年（6段階）× 計算の種類（5種）× モード（2種）× 問題数/制限時間の選択肢

## 画面構成

| 画面 | 内容 |
|------|------|
| トップ画面 | 学年・計算の種類・モード・問題数/時間を選択してスタート |
| ゲーム画面 | 問題・入力エリア・キャラクター・経過時間/残り時間を表示 |
| 結果画面 | 正解数・時間・ランキング表示・名前入力（ランクイン時）・バッジ獲得演出 |
| ランキング画面 | 条件を選んでランキング一覧を表示 |
| コレクション画面 | バッジ一覧・獲得済みイラストのギャラリー表示 |
| 設定画面 | 入力方法の切り替え・ユーザー登録・ランキングリセット |

### 設定画面の詳細

| 項目 | 内容 |
|------|------|
| ユーザー登録・編集 | 名前・キャラクター・学年を登録／複数ユーザー対応 |
| 入力方法 | キーボード入力 / タッチボタンを切り替え |
| ランキングリセット | 全ランキングデータを削除（確認ダイアログあり） |
